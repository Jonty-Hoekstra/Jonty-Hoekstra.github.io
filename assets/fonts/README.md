# Fonts

Latin subsets in WOFF2, downloaded from Google Fonts. All three families use the [SIL Open Font License 1.1](https://openfontlicense.org/), which allows self-hosting.

| File | Family | Weights |
|---|---|---|
| `chakra-petch-600.woff2`, `chakra-petch-700.woff2` | Chakra Petch | 600, 700 |
| `space-grotesk-variable.woff2` | Space Grotesk (variable) | 300–700 |
| `jetbrains-mono-variable.woff2` | JetBrains Mono (variable) | 100–800 |
